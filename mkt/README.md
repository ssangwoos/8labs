# 8labs.kr/mkt/

## 파일

```
index.html          마케팅 페이지 + 문의 게시판   → 공개
admin.html          문의 관리 + 클라이언트 관리    → 로그인 필요
dashboard.html      클라이언트 캠페인 대시보드     → 로그인 필요
firestore.rules     보안 규칙 (콘솔에 붙여넣어야 적용)
firebase.json       배포 설정
.firebaserc         프로젝트 지정
functions/index.js  비밀번호 변경 · 계정 삭제 (서버)
functions/package.json

```

웹서버에 올릴 건 **HTML 세 개**뿐입니다. 나머지는 설정·소스입니다.

세 HTML 모두 이미지·설정이 내장돼 있어 그대로 올리면 됩니다.
GitHub 에는 위 다섯 개를 모두 올리셔도 됩니다.

| 주소 | 누가 |
|---|---|
| `8labs.kr/mkt/` | 누구나 — 문의 등록 |
| `8labs.kr/mkt/admin.html` | 에이트랩스 (staff 계정) |

## 1. 최초 세팅 (한 번만)

프로젝트: `promptmarket-c3c3a`

### ① Firestore

콘솔 → **Firestore Database** → 데이터베이스 만들기 → **프로덕션 모드**
→ **규칙** 탭 → `firestore.rules` 전체 붙여넣기 → **게시**

> 규칙을 안 넣으면 비공개가 걸리지 않고, 관리자 화면도 열리지 않습니다.

### ② 로그인 켜기

**Authentication** → Sign-in method → **이메일/비밀번호** 사용 설정

### ③ 관리자(본인) 계정 만들기

Authentication → **Users** → 사용자 추가 → 이메일 + 비밀번호

관리자 판별은 **규칙에 적힌 이메일**로 합니다. 별도 문서를 만들 필요 없습니다.
`firestore.rules` 의 이 부분과 `functions/index.js` 의 `STAFF` 를 같은 값으로 맞춰 주세요.

```
request.auth.token.email in ['8_beauty@naver.com']
```

관리자를 늘릴 때는 두 곳의 목록에 이메일만 추가하고 다시 게시·배포하면 됩니다.

### ④ 비밀번호 변경 기능 배포 (한 번만)

브라우저에서 도는 코드는 남의 비밀번호를 바꿀 수 없습니다.
그 권한을 브라우저에 주면 키를 가진 누구나 계정을 탈취할 수 있기 때문입니다.
그래서 이 한 가지만 서버(Cloud Functions)에서 처리합니다.

```powershell
cd "C:\Users\ssang\OneDrive\Desktop\에이트랩스\홈페이지\mkt"

npx firebase-tools login                       # 최초 1회
npx firebase-tools deploy --only functions
```

- Blaze 요금제가 필요합니다 (이미 쓰고 계십니다)
- 처음 배포할 때 필요한 API 를 켜도 되냐고 물으면 **예**
- 규칙도 같이 올리려면 `--only functions,firestore:rules`

배포 전까지는 admin 화면의 `변경` 버튼이
"함수가 아직 배포되지 않았습니다" 로 안내합니다.

## 2. 클라이언트 추가하는 법

`admin.html` 로그인 → **클라이언트** 탭 → `+ 새 클라이언트`

1. **기본 정보** — 업체명, 대시보드 제목, 브랜드, 캠페인, 기간, 플랫폼
2. **패키지** — 패키지명 · 회차 수 · 크리에이터 인원
   (금액은 저장하지 않습니다. 클라이언트에게는 패키지명 · 회차 · 인원 · 진행률만 보입니다)
3. **클라이언트 계정** — 이메일 입력 → `비밀번호 자동 생성` → `계정 만들기`
   - 이메일은 실제로 없는 주소여도 됩니다 (예: `lumiere@8labs.kr`). 로그인 아이디로만 쓰입니다
   - 발급된 비밀번호는 **그 화면에서만 보입니다.** 바로 복사해 업체에 전달하세요
   - 계정을 만들어도 **저장을 눌러야** 연결이 기록됩니다
   - 나중에 바꿀 때는 `새 비밀번호` 칸에 넣고 **변경** — 즉시 적용되고 저장을 누를 필요 없습니다
4. **표시 항목** — 체크를 끄면 그 업체 대시보드에서 숨겨집니다
5. **크리에이터** — 엑셀에서 복사해 붙여넣거나, 표에서 직접 수정
6. **저장**

업체에는 `8labs.kr/mkt/dashboard.html` 주소와 계정을 전달하면 됩니다.
로그인하면 자기 캠페인이 자동으로 열립니다. 링크에 업체 코드가 없습니다.

### 붙여넣기 형식

탭 또는 두 칸 이상 공백으로 구분합니다. 순서는 자유롭고 알아서 인식합니다.

```
@handle      147000   Instagram   업로드완료   2026-07-19   2026-07-24   396000   https://...
2차  @handle2  7855    TikTok      방문완료     2026-07-17
섭외 진행 #9                        확정
```

- 맨 앞에 `2차` 처럼 숫자가 오면 회차로 인식합니다 (없으면 1차)
- 상태: `확정` / `방문완료` / `업로드완료`
- 날짜는 `YYYY-MM-DD` 두 개까지 (앞이 방문일, 뒤가 업로드일)
- 숫자 두 개까지 (앞이 팔로워, 뒤가 조회수)
- 크리에이터명이 `@` 로 시작하지 않으면 클라이언트 화면에서 회색 처리됩니다

`추가` 는 이어붙이고, `전체 교체` 는 기존 목록을 지우고 새로 넣습니다.

## 3. 데이터 구조

```
board/{id}                     createdAt · status · secret     ← 공개, 내용 없음
board/{id}/private/detail      회사명 · 담당자 · 이메일 · 내용   ← 로그인 필요
clients/{id}                   name · ownerUid · ownerEmail
                               package · meta · config
clients/{id}/creators/{k}      round · handle · followers · platform
                               status · visit · post · views · url
```

클라이언트는 `ownerUid` 가 자기 uid 인 문서만 읽을 수 있습니다.
A 업체 계정으로 B 업체 데이터를 볼 수 없습니다.

## 4. 알아둘 것

- **패키지 금액은 저장하지 않습니다.** 클라이언트가 볼 화면이므로 원가·마진이 역산될 여지를 두지 않았습니다.
- **클라이언트를 삭제하면 로그인 계정도 함께 지울지 물어봅니다.** 취소하면 계정은 남습니다.
- 관리자 계정 자체는 이 화면에서 비밀번호 변경·삭제가 되지 않도록 서버에서 막아뒀습니다.
- **apiKey 는 비밀번호가 아닙니다.** 브라우저가 읽어야 동작하므로 공개됩니다.
  실제 방어선은 위 규칙과 Authentication → Settings → **승인된 도메인**(`8labs.kr`) 입니다.
- 서비스 계정 JSON 은 진짜 비밀키입니다. 이 폴더에 두지 마세요.
